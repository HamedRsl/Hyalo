Behavior and accessibility

Items must have a fixed size along the scrolling axis. The native scroll container exposes list positions and total counts. A small label-only list remains useful during SSR and before the viewport is ready. Loading, error, retry, empty state, rendered ranges, and index changes are part of the public contract. Use the existing virtual-list when you need its richer keyboard list behavior.
