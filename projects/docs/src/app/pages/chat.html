Compose, don’t configure a chat kit

Scroll area contains a native ordered history. Card supplies the solid content surface; Avatar, Text field and Button supply the rest. Change the listing, sender layout, bubbles or delivery labels directly in your template and local records. There is no conversation API or AI dependency.

Import the primitives

Application boundaries

This is local demo state, not a transport. Add and edit local drafts, then use the explicit preview buttons to inspect pending, failure and retry. Pending blocks the composer until you choose a result; it never advances on a timer. The fixed demo date also applies to new drafts. Attachment URLs accept absolute HTTP or HTTPS links; unsafe or malformed destinations render as unavailable text. The sample PDF is a public dummy file, not listing evidence. Validate and authorize uploads on your server. Connect your own persistence, authorization, upload validation and delivery acknowledgements. Render messages as plain text; never pass untrusted messages into HTML. ISO instants are displayed with en-GB and UTC explicitly, rather than the visitor’s machine defaults.

Keyboard and reading order

The named scroll region is keyboard focusable. History is not a live region and does not autoscroll or steal focus while you read. The labelled textarea keeps Enter and IME composition native; submit with the button. Logical CSS follows the page direction.
