Behavior and accessibility

Messages are rendered as text, never HTML. Native attachment links and retry buttons remain keyboard accessible. Near-bottom autoscroll preserves a reader browsing history, offers a New messages button, and compensates for prepended history. Live announcements are off by default to avoid replaying server-rendered history. Use HyChatComposer or project a custom composer through hyChatComposer; transport, uploads and message persistence remain application responsibilities.

Design tokens

Uses shared surface, ink, spacing, radius, focus, semantic tone and motion tokens. Override local component variables on the host; reduced motion, forced colors and fidelity retain functional controls.
