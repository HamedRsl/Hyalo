Import

Behavior and accessibility

Notifications are immutable application data. Read, dismiss, mark-all and clear outputs request changes from the host. Filtering and sorting copy the data. Dates use explicit locale and timezone, with a deterministic UTC default. HyNotificationCard is exported for standalone push-card presentation; announce is opt-in. Use HyToast for transient messages rather than duplicating a notification queue.

Design tokens

Uses shared surface, ink, spacing, radius, focus, semantic tone and motion tokens. Override local component variables on the host; reduced motion, forced colors and fidelity retain functional controls.
