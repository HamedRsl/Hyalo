    Import

    Behavior and accessibility

    Copy the complete TypeScript, HTML and CSS above into your application. The local store owns immutable data, filtering and read/dismiss actions; no notification wrapper or notification service is required. The popover owns focus, Escape and outside-click dismissal. Tabs provide keyboard navigation, rows retain native list semantics and actions are separate native buttons. Push cards do not announce on initial render. Use a polite live region only for genuinely new incoming updates, and use Toast for transient feedback, not another notification queue.

    Design tokens

    Uses shared surface, ink, spacing, radius and focus tokens. The panel and badges use solid material, so there is no repeated row blur. Layout uses logical properties for RTL; local controls and tab headers provide 44px touch targets. The popover owns motion and fidelity fallbacks, and the full panel scrolls as one surface on short screens.

    Legacy API reference

    The existing notification-center package remains compatible. These legacy exports are not used by the copyable composition above.
