Behavior and accessibility

The accessible text is exposed once; visual line fragments are hidden from screen readers. Resizing and font loading remeasure the lines. Content is present during server rendering and when observers are unavailable. Motion follows HyMotion and uses the shared scene duration with a 60 ms line stagger.

Themes and fidelity

Use the toolbar to check light and dark themes, RTL, reduced motion and the three fidelity tiers. Surfaces, text, borders and spacing read the shared Hyalo tokens.
