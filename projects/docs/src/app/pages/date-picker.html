Behavior and accessibility

Type YYYY/MM/DD in the selected calendar, or open Calendar. Arrow keys move by day or week; Home/End move within a week; Page Up/Down change month and Shift changes year. Escape returns focus. Jalali years 1200 through 1600 are supported. Range endpoints are inclusive date-only values; convert to timestamp boundaries in your application.

API

Install the optional jalaali-js peer when importing the dates entry point. Parsing and availability errors expose validationError() and validationChange; connect the latter to an Angular validate() rule in your host form. Native forms also receive custom validity.

value: HyDate | null, adapter: HyDateAdapter<HyDate>, locale, min, max, referenceDate, isDateDisabled; range value: HyDateRange | null

All controls expose disabled, readonly, required, invalid, touched, errors, name, label, touch, and focus(). Use hy-field for a visible label and hint. Bind value or checked directly, or use Angular Signal Forms. For typed Reactive Forms, wrap your FormControl in Angular's compatForm and bind its resulting field with FormField.
