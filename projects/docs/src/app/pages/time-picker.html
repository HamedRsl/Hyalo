Behavior and accessibility

The control stores a local wall time. Booking applications must resolve the date, IANA timezone, and ambiguous or nonexistent DST times on their server. Disabled slots remain visible.

API

Use confirmSelection to hold changes until confirmation. footerTemplate receives the picker as its implicit context and the current draft as draft.

value: string (HH:mm), slots, min, max, step (seconds)

All controls expose disabled, readonly, required, invalid, touched, errors, name, label, touch, and focus(). Use hy-field for a visible label and hint.
