Host-owned actions

The blocks emit requested values and accept pending and error state. Applications own authentication, availability, payment processing, file transfers, persistence, and server validation. Never log passwords or OTP values.

Date and time contract

Dates are Gregorian ISO date-only strings. Calendar choice changes the editor, not stored values. Booking times are local wall times with an explicit IANA timezone. The host resolves DST gaps and overlaps. Dashboard timestamp filters use start-inclusive, end-exclusive instants, with UTC midnight as the documented demo boundary.

Forms interoperability

Use FormField from Angular Signal Forms. For typed Reactive Forms, put existing FormControl instances inside a signal model and create the field tree with compatForm from @angular/forms/signals/compat. Reset, touched, disabled, and value state then flow through Angular's native bridge.
