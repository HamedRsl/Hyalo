Behavior and accessibility

Links remain native links in both modes. Use hy-sidebar-group around projected links with routerLink, or supply href-based data to hy-sidebar-groups. The selected output reports activation and leaves navigation to the browser.

Descriptions and counts remain in accessible names when collapsed. Empty configured groups are omitted. Role filtering, route state, and authorization belong to the host application.
