Name: {{ collection() }}

Content is any component or template. Lay it out with hyDialogTitle, hyDialogContent and hyDialogActions, and close it with [hyDialogClose] or HyDialogRef.close().

Accessibility

  • Focus moves into the dialog, stays there, and returns to the trigger on close.
  • hyDialogTitle names the dialog. Without a title, pass label.
  • Escape and a backdrop click close it, unless dismissible is false.
  • Confirm uses role="alertdialog" and starts on the safe button.

API

HyDialog.open(content, config) returns a HyDialogRef.

HyDialog.confirm(options) resolves to true or false.
