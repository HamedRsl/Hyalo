Dialog geometry

{{ description }}

Use width, height, minWidth, maxWidth, minHeight, maxHeight and positionStrategy for the initial geometry. Update it with updateGeometry() and updatePosition(). While it enters, focus stays trapped on the dialog. It moves to Widen when entry finishes, unless the user has already moved focus within the dialog. Dismissal restores focus to the configured trigger. closeOnEscape, closeOnBackdrop and hasBackdrop are independent. Add hyDialogDragHandle to a button to enable pointer and arrow-key movement. Call setMaximized() to fill the viewport and restore the previous geometry.

opened and beforeClosed report entry and accepted closing. backdropClick, keydownEvents and outsidePointerEvents expose interactions. Use getById(), openDialogs, closeAll() and afterAllClosed to manage dialogs and drawers together.

Use injector or viewContainerRef to control creation context, and bindings for component inputs or templateContext for template locals. autoFocus selects the initial focus target and restoreFocus selects the destination on close. Use ariaLabelledBy and ariaDescribedBy for existing element IDs. closeOnNavigation follows browser history traversal and closeOnScroll observes scrolling outside the dialog. Both pass through closeGuard.

For asynchronous confirmation, pass confirm and optionally errorMessage. A pending action disables both buttons. Returning false leaves the confirmation open, and a rejected action announces the error and allows a retry.

Accessibility

  • Focus moves into the dialog, stays there, and returns to the trigger on close.
  • hyDialogTitle names the dialog. Without a title, pass label.
  • Escape and a backdrop click close it, unless dismissible is false.
  • Confirm uses role="alertdialog" and starts on the safe button.

API

HyDialog.open(content, config) returns a HyDialogRef.

HyDialog.confirm(options) resolves to true or false.
