Import

Behavior and accessibility

Rows have exact heights, including padding and borders. Taller content is clipped. Use ordinary lists or pagination for variable-height content, full-document search, printing, or workflows that need every row in the accessibility tree.

Use orientation with columnWidth and columnCount for a horizontal strip or a two-axis fixed-cell grid. scrollTo() uses pixels from the logical start. scrollToIndex() accepts start, center, end or nearest alignment. rangeChange emits when the rendered item interval changes.

Use loadRange to fetch missing entries into a caller-owned cache. A grid requests complete row intervals. Superseded requests receive an abort signal. The row template can render a hy-skeleton while its entry is loading, as in Preview loading. Use retry() after a failure. appendOnly retains visited rows on the scrolling axis and increases DOM usage. virtual set to false renders every item. Replacing the items or switching modes resets retained rows.

Tab reaches the viewport. Arrow keys move between rows, Home and End reach the ends, and Page Up and Page Down move a viewport. Embedded controls retain their own keys.

Rows expose aria-posinset and aria-setsize. Focus moves to the viewport before scrolling evicts a focused row or filtering removes it. Stable keys preserve identity. This primitive does not add table virtualization.
