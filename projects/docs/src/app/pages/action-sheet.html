Import

Behavior and accessibility

Disabled actions cannot emit. Cancel actions are placed last and only dismiss; an implicit Cancel button appears when none is supplied. Destructive actions use the danger tone. Native buttons retain normal keyboard activation. The selected output requests work from the application; it never deletes data itself.

Design tokens

Uses shared surface, ink, spacing, radius, focus, semantic tone and motion tokens. Override local component variables on the host; reduced motion, forced colors and fidelity retain functional controls.

API

An action sheet offers a short list of commands and an optional cancel action. Use a bottom sheet when people need to read, edit, or interact with custom content.
