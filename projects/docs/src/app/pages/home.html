Install

npm install @hyalo/angular @angular/cdk @angular/aria

Add the stylesheet to angular.json, before your own styles:

"styles": ["node_modules/@hyalo/angular/styles/hyalo.css", "src/styles.css"]

hyalo.css includes the styles of every overlay. To ship only the ones you use, list hyalo-core.css instead, plus a file from styles/overlays/ for each overlay: select.css, popover.css, dialog.css or toast.css.

Then import what you use. Every component is standalone:

{{ usage }}

Optional setup

provideHyalo() sets defaults for the whole app or one part of it. Pass a GSAP loader if you want cursor effects to glide with GSAP. Without it they fall back to CSS transitions, and GSAP never enters your bundle. 

{{ config }}

What "done" means here

Each component on these pages ships with:

  • full keyboard support and visible focus,
  • right-to-left layout through logical CSS properties,
  • light and dark themes, and a high contrast fallback,
  • reduced motion and three fidelity tiers, with content never hidden behind JavaScript,
  • an axe check in its unit tests.

Use the settings button in the top bar to switch theme, direction, motion and fidelity on any page.
