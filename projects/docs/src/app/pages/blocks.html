Plans use stable IDs and a controlled monthly/annual billing model. Features, testimonials, KPIs and activity accept readonly data with stable IDs; replace arrays when data changes. Activity dateTime values are ISO instants. Static content and CSS Grid need no graphics engine; enhancement belongs inside the media slot.

Hosts own loading, errors, empty data and success: keep the section mounted, set aria-busy on its region, show a named status or alert and offer a native retry button. Do not turn a sample quote, price, billing selection or request event into a claim of backend success. Dense repeated cards use tinted material.
