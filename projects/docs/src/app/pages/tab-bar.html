Behavior and accessibility

Use the tab bar for app destinations and HyTabs for panels on the same page. The active link has aria-current page. Every enabled destination remains in native Tab order; arrow keys add spatial navigation, including RTL. Fixed mode reserves safe-area offsets; the application must reserve space for fixed chrome.

Design tokens

Uses shared surface, ink, spacing, radius, focus, semantic tone and motion tokens. Override local component variables on the host; reduced motion, forced colors and fidelity retain functional controls.
