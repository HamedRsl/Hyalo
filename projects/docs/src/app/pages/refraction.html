Import

Behavior and accessibility

WebGL runs only on high fidelity. One shared WebGL canvas renders all surfaces and copies into their presentation canvases. It renders on image load, input changes and resize, with no continuous animation. Context loss, CORS failure and unavailable WebGL retain CSS glass. It refracts the supplied image, not arbitrary DOM content. Medium and low tiers use CSS; reduced transparency hides decorative image layers.

Themes and fidelity

Use the toolbar to check light and dark themes, RTL, reduced motion and the three fidelity tiers. Surfaces, text, borders and spacing read the shared Hyalo tokens.
