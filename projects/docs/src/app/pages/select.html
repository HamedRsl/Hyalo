Native fallback

Use compact for toolbars to keep the chevron next to the value. A standalone select uses label for its accessible name.

The themed dropdown adapts its materials to the active fidelity tier. Use native for the platform picker or nativeOnLowFidelity to enable it on the low tier.

Call open() from a user gesture to request the platform picker where the browser supports it. The native picker owns dismissal and visibility. The open state and panel events describe the custom dropdown.

Accessibility

  • Follows the APG select-only combobox pattern. Enter, Space or Down open the list.
  • Typing a letter jumps to the next option that starts with it. Use typeaheadDelay to set the search window and wrap to control what arrow keys do at the list edges.
  • Escape closes without changing the value. Focus stays on the trigger the whole time.
  • Use Combobox when people need editable search, clear or query-based loading. Use Multi-select to select multiple values.

Custom panels accept loadPage and show emptyLabel when the loaded list has no options. A createValue callback may return undefined to reject the draft. Rejections and exceptions are reported through customValueRejected, and the draft remains editable.

Use clear() to restore the placeholder when the field is optional. An undefined option is a reset action. A null option can carry its own label.
