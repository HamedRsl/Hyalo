Behavior and accessibility

The viewport supports Arrow keys, Home and End. The buttons keep their native focus behavior. Touch uses browser scroll inertia. Mouse gestures project release velocity to a slide; interactive slide children keep their own pointer behavior. Slides may contain links and form controls. There is no autoplay. The scrollbar is hidden by default; dot navigation provides a visible alternative. Fade uses only opacity and keeps inactive slides inert. Low fidelity and reduced motion disable transitions. The transitionCompleted output reports the latest settled slide after model changes, native scrolling or a fade.
