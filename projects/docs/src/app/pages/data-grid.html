Behavior and accessibility

Use arrow keys to navigate the grid and F2 to edit. Shift-click a heading for multiple sorts. Save/cancel controls also work without keyboard shortcuts. Drag headings to reorder; moveColumn provides the same operation for application controls. Resize handles accept arrows, Shift-arrows, Home, and End. Virtual rows require a fixed height; expanded row details use the regular renderer. In lazy mode the host fetches each query and supplies totalRecords. Persist state explicitly with saveState and restoreState; exportCsv escapes spreadsheet formulae by default.
