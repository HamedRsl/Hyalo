A switch takes effect right away, like a setting. A checkbox is a choice that is submitted later, like a form field. If there is a Save button, use a checkbox.

Accessibility

  • Each control is a real input, so labels, form submit and browser autofill all work.
  • The whole row, including the description, is the click target.
  • Radios inside a group move with the arrow keys and share one tab stop.
  • Mixed checkboxes announce themselves as mixed through the native indeterminate state.
