Behavior and accessibility

Escape and a backdrop click close the viewer. Arrow keys follow reading direction. The CDK traps focus and restores it to the thumbnail. Zoom in to pan with a pointer or focus the image area and use arrow keys. Flip either axis or reset the image from the toolbar. Provide alternative text for custom preview images. The thumbnail button already has a label, so its decorative image uses empty alternative text. The grid adds a column whenever the container can fit one more minimum-width thumbnail and its gap. Updates to the image list and viewer options apply while the gallery is open. Removing all images closes the viewer. A service-opened viewer exposes update() and a transform signal with the current scale, rotation, pan and flips. Include styles/overlays/dialog.css if using the core stylesheet.
