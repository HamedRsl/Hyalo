Behavior and accessibility

Filtering retains matching ancestors and sorting runs within siblings. Expansion and selection use node keys. Arrow Right opens a branch; Arrow Left closes it or focuses the parent. The first column accepts its own template inside the expansion cell. loadRequested signals an unloaded branch; the host supplies its children and loadingKeys. Pagination is deliberately disabled so parents cannot be stranded on another page. Grid options still control virtualization, editing, column sizing, templates, and selection.
