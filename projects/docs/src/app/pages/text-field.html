With Signal Forms

EUR

Required, invalid, touched and the error messages come from the bound field. Errors show after the user leaves the field or tries to submit, never while they are still typing the first time.

Without forms

Accessibility

  • The label, hint and error are linked with for and aria-describedby.
  • The error region is polite, so a new message is read without stealing focus.
  • Required fields get a visual star that screen readers skip, since the input already says required.
  • Keep the label visible. A placeholder is not a label.

API

hy-field

input[hyInput], textarea[hyInput], plus [hyPrefix] and [hySuffix] for content inside the box. Everything comes in HY_TEXT_FIELD.
