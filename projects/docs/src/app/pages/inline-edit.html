Behavior and accessibility

Enter commits a single line, Escape discards the draft, and multiline values always use the Save button. Validation keeps an invalid draft open. Leaving focus does not silently commit.

API

value: string, multiline, placeholder, validate: (draft) => string | undefined, saved: output<string>

All controls expose disabled, readonly, required, invalid, touched, errors, name, label, touch, and focus(). Use hy-field for a visible label and hint. Bind value or checked directly, or use Angular Signal Forms. For typed Reactive Forms, wrap your FormControl in Angular's compatForm and bind its resulting field with FormField.
