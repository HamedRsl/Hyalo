Behaviour

  • Links are wrapped in a <nav> named by label. Mark the current page with aria-current="page", for example through ariaCurrentWhenActive.
  • The collapse point is a container query on the navbar's own width (48rem), so it works inside any layout.
  • Escape closes the menu and returns focus to the menu button. Choosing a link closes it too.
  • With hideOnScroll the bar slides away while scrolling down. It never hides while the menu is open or focus is inside.
  • To open your own drawer instead of the built-in panel, bind [(menuOpen)].
