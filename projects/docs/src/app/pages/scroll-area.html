Import

Behavior and accessibility

The region is keyboard focusable so arrow keys and Page Up/Down work natively. Touch keeps native inertia. Supply scrollHost to use a different native viewport. Set its overflow, size and focusability in the application. Overscroll is contained. Avoid nesting multiple scroll areas on a small screen.

Themes and fidelity

Try light and dark themes, every palette, RTL, reduced motion, and low fidelity using Display settings. Colors, spacing, and focus rings follow the existing Hyalo tokens.
