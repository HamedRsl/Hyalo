Import

Behavior and accessibility

The grid responds to its container, not the entire viewport. Source order and reading order stay the same. Spans collapse on narrow containers. No layout animation, drag controls, or reordered tab stops.

API

Themes and fidelity

Try light and dark themes, every palette, RTL, reduced motion, and low fidelity using Display settings. Colors, spacing, and focus rings follow the existing Hyalo tokens.
