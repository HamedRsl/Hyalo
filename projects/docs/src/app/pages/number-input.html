Behavior and accessibility

Persian and Eastern Arabic digits are accepted. Display separators follow the selected locale. Arrow Up/Down and the step buttons change the number. Invalid or incomplete drafts never silently become another amount; the host owns currency rounding and business validation.

API

validationChange reports parsing failures; the example connects it to Angular validate(). validationError() exposes the current message, and validationMessage customizes it. Native forms also receive custom validity.

value: number | null, locale, currency, min, max, step

All controls expose disabled, readonly, required, invalid, touched, errors, name, label, touch, and focus(). Use hy-field for a visible label and hint. Bind value or checked directly, or use Angular Signal Forms. For typed Reactive Forms, wrap your FormControl in Angular's compatForm and bind its resulting field with FormField.
