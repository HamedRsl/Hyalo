Three layers

  • System tokens such as --hy-primary and --hy-radius-m set the look of everything at once.
  • Component tokens such as --hy-button-radius change one component. They are unset by default and fall back to a system token.
  • Palettes are ready-made sets of colour tokens, loaded on demand. See Foundations.

--hy-primary is the brand colour. --hy-secondary is optional: set it to give a theme a second colour for tone="secondary". Left unset, secondary controls use the primary colour, so a theme with one colour needs nothing extra.

Hyalo puts all of its CSS in cascade layers, so a plain rule in your own stylesheet always wins. No !important, no specificity tricks.

Overriding tokens

Set a token on :root for the whole app, or on any element for everything inside it. Use light-dark() when a colour needs a different value in dark mode. 

{{ overrideCode }}

A few tokens are built from others on :root, like --hy-focus-ring. When you change --hy-primary on a single element, set --hy-primary-hover, --hy-primary-wash and --hy-focus-ring there too.
