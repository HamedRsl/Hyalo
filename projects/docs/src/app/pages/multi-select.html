Use Page Down or Load more teams to request another page. Selected teams stay visible while you search.

Behavior and accessibility

Selections stay in the host model while the query changes. Chip removal is a labeled button. An empty selection is an empty array. Disabled options cannot be newly selected.

The remote example shows a fixed width, explicit position and offsets, and a scroll strategy that keeps the panel in place. Use Escape to close it when outside pointer dismissal is disabled. The panelAttached and panelDetached outputs report when the popup actually mounts and unmounts.

API

value: readonly T[], options, loadOptions, loadPage, pageSize, loadMore(), loadMoreLabel, locale, placeholder

All controls expose disabled, readonly, required, invalid, touched, errors, name, label, touch, and focus(). Use hy-field for a visible label and hint. Bind value or checked directly, or use Angular Signal Forms. For typed Reactive Forms, wrap your FormControl in Angular's compatForm and bind its resulting field with FormField.
