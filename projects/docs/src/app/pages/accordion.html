Accessibility

  • Each header is a real heading with a button inside. Pick headingLevel to fit the page outline.
  • Up and Down move between headers, Home and End jump to the ends.
  • Closed panels are hidden from the accessibility tree, not just collapsed.
  • The height animation uses grid rows, so content of any size opens smoothly and reduced motion turns it off.
