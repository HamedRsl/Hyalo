Segmented

Use tabs when each option has its own panel. Use segmented when the choice is a value, like a filter or a setting. Segmented is a group of native radios, so it submits with forms and works with [formField].

Accessibility

  • Tabs follow the APG tabs pattern. Arrow keys move and select, mirrored in RTL. Home and End jump.
  • Set selectionMode="explicit" when a panel is expensive, so arrows only move focus and Enter selects.
  • Hidden panels are inert, so their links leave the tab order.
  • Give both a label when the page has more than one set.
