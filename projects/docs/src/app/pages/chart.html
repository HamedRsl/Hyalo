Import

Install the optional chart engine with npm install chart.js.

Behavior and accessibility

Install chart.js as an optional peer only when using this entry point. The engine loads near the viewport. Charts reserve height, disable animation, and dispose their canvas instance on destroy. The data table is available during loading, on the server, and if the engine fails. Theme and direction changes refresh colors and labels. Set --hy-chart-height to size the plot.

API

Themes and fidelity

Try light and dark themes, every palette, RTL, reduced motion, and low fidelity using Display settings. Colors, spacing, and focus rings follow the existing Hyalo tokens.
