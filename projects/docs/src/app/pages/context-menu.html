Behavior and accessibility

Right-click, the Context Menu key, Shift-F10, and the visible action button open the same menu. Set a positive longPressDelay to open on a touch hold. Moving the pointer cancels the hold so users can scroll. Arrow keys navigate the menu and its submenus. Escape dismisses and restores focus to the trigger by default. Use restoreFocus to choose a different target or disable focus restoration.

Actions support icons, shortcuts, visibility, separators, checkboxes, radio choices, nested actions, and custom templates. The host owns checked state and action effects.
