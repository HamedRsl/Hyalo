Behavior and accessibility

Right-click, the ContextMenu key, Shift-F10, and the visible action button share one CDK menu. Arrow keys navigate, submenus retain the CDK focus stack, and Escape dismisses. Menu items support icons, shortcuts, hidden/disabled state, separators, checkboxes, radio actions, and custom templates. The host owns checked state and action effects. Position overrides and contextual template data are forwarded from the CDK trigger.

Complete component API
