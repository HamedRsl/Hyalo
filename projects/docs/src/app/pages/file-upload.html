Behavior and accessibility

This example simulates progress locally. An application-supplied uploader receives a file, abort signal, and progress callback. Rejected selections are announced with their reason.

Directory mode accepts a native folder selection or a folder dropped from a browser that supplies file-system entries. Relative paths are retained.

API

value: readonly File[], accept, multiple, maxSize (bytes), maxFiles, rejected: output<string[]>

Call addFiles(files) to queue files from a custom picker or camera input. It applies the same preparation and validation as browsing or dropping files.

With an uploader, Hyalo renders upload, progress, cancel and retry controls. The labels object can localize actions, progress, status and validation feedback. Bind fileTemplate for the file and its transport state, and toolbarTemplate for queued files and the upload controller.

All controls expose disabled, readonly, required, invalid, touched, errors, name, label, touch, and focus(). Use hy-field for a visible label and hint. Bind value or checked directly, or use Angular Signal Forms. For typed Reactive Forms, wrap your FormControl in Angular's compatForm and bind its resulting field with FormField.
