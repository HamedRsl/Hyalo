Behavior and accessibility

CDK menu primitives own arrow keys, typeahead, Escape, submenu direction, and focus return. Use menus for actions. Website destinations belong in navigation. Keep checked values in application state.

For pointer-positioned actions or a recursive data model, use HyContextMenu.

Set panelClass to style the menu and hasBackdrop to consume the outside click that closes it.

Bind restoreFocus to a focusable element to return there, or set it to false when the application manages focus.

Themes and fidelity

Try light and dark themes, every palette, RTL, reduced motion, and low fidelity using Display settings. Colors, spacing, and focus rings follow the existing Hyalo tokens.
