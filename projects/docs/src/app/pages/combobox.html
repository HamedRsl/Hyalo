Behavior and accessibility

Arrow keys navigate results; Enter selects; Escape closes. Local matching normalizes Persian and Arabic letter variants. Object values need stable keys. For remote search supply loadOptions(query, signal), and pass the signal to your request. Obsolete requests are cancelled; loading, retry, and empty states are separate from the selection.

API

value: T | undefined, options: HySelectOption<T>[], loadOptions: (query, AbortSignal) => Promise<options>, locale, placeholder

All controls expose disabled, readonly, required, invalid, touched, errors, name, label, touch, and focus(). Use hy-field for a visible label and hint. Bind value or checked directly, or use Angular Signal Forms. For typed Reactive Forms, wrap your FormControl in Angular's compatForm and bind its resulting field with FormField.
