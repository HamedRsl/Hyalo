Search for at least two letters. Enter unavailable to preview a failed request.

Behavior and accessibility

Arrow keys navigate results; Enter selects; Escape closes. Local matching normalizes Persian and Arabic letter variants. Object values need stable keys. For remote search supply loadOptions(query, signal), and pass the signal to your request. Obsolete requests are cancelled; loading, retry, and empty states are separate from the selection.

The remote example shows a fixed width, explicit position and offsets, and a scroll strategy that keeps the panel in place. Use Escape to close it when outside pointer dismissal is disabled. The panelAttached and panelDetached outputs report when the popup actually mounts and unmounts.

API

value: T | null, options: HySelectOption<T>[], loadOptions: (query, AbortSignal) => Promise<options>, clearable, clearLabel, clear(), valueCommitted, locale, placeholder

All controls expose disabled, readonly, required, invalid, touched, errors, name, label, touch, and focus(). Use hy-field for a visible label and hint.
