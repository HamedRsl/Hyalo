Behavior and accessibility

Use a positioned scene wrapper. Project world-space coordinates in your renderer and supply screen percentages; mirror x in an RTL scene when your renderer uses physical left coordinates. Set visible to false for occluded points so they leave the tab order. Enter and Space activate the native button. Details use the existing lazy popover overlay and stay visible beside the trigger. When using the core stylesheet, include styles/overlays/popover.css for the detail panel.

Themes and fidelity

Use the toolbar to check light and dark themes, RTL, reduced motion and the three fidelity tiers. Surfaces, text, borders and spacing read the shared Hyalo tokens.
