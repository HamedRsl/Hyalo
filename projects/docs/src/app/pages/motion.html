Timing

Three presets cover almost everything. settle is the default for things moving into place. pop overshoots a little and is only for motion the user caused, like a switch they just flipped. quick is for acknowledgements such as a press. The same values exist as CSS tokens (--hy-dur-settle, --hy-ease-out and so on) and as the MOTION constant for GSAP.

Fidelity tiers

HyFidelity picks high, medium or low from device memory, CPU cores, pointer type and data saver. Reduced motion does not lower the tier: it turns off decorative motion and makes overlays cross-fade, but the glass stays. The server and the first client render always use medium, so hydration sees identical markup, and the real tier is set right after. This page is on {{ fidelity.tier() }} right now, and motion is {{ motion.reduced() ? 'reduced' : 'full' }}.

  • High: everything, including cursor physics.
  • Medium: tilt, magnetic hover and reveals.
  • Low: CSS only. Glass is solid, cursor effects are off, the select is native.
